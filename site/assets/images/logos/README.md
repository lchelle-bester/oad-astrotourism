# OAD logo files

Official OAD logo files, copied unaltered from the "OAD Logo" Drive folder. Only the names were changed.
Never recolour, redraw, stretch or crop these (Corporate Identity 2021, p.10). To use a file, pick it from the table below by background and purpose.

Naming pattern: `oad-<symbol or logo-full>-<colour>-<background>-<width>.<ext>`
"symbol" is the orbit mark with OAD inside. "logo-full" adds the "International Astronomical Union | Office of Astronomy for Development" line.

| File | Shows | Background | Use it for |
|---|---|---|---|
| `oad-logo-full-colour-transparent-for-dark-bg-1024.png` | Full logo, coloured rings, white OAD and text | Transparent (invisible on white) | Header and footer on the navy site. Default choice. |
| `oad-logo-full-black-transparent-for-light-bg-1024.png` | Full logo, all black | Transparent | Anything on a light or sand background, print-style panels |
| `oad-logo-full-white-transparent-for-dark-bg-300.png` | Full logo, all white | Transparent (invisible on white) | Single-colour white version over a busy photo or the hero video. Only 300px wide. |
| `oad-logo-full-colour-on-black-1024.jpg` | Full logo, coloured, solid black square | Opaque black | Social previews only. Not for the page (the black box shows). |
| `oad-logo-full-white-on-black-1024.jpg` | Full logo, white, solid black square | Opaque black | Social previews only. Not for the page. |
| `oad-symbol-black-transparent-for-light-bg-1024.png` | Symbol only, black | Transparent | Small mark on light backgrounds |
| `oad-symbol-colour-transparent-for-dark-bg-300.png` | Symbol only, coloured, white OAD | Transparent (invisible on white) | Small mark on dark backgrounds, favicon source |
| `oad-symbol-colour-on-black-300.jpg` | Symbol only, coloured, solid black square | Opaque black | Avatars and social profile images only |
| `oad-logo-full-with-partners-transparent-1024x938.png` | Symbol, plus DSI, IAU and NRF/SAAO logos in a row | Transparent | Footer partner band. See notes. |

## Notes

- Files marked "invisible on white" have white text. They look empty on a white background, which is expected.
- The coloured logo has a navy ring (about #404470). On the site's deep navy (#1e3551) that ring has low contrast. Check it in the header before committing to this file.
- The partner file mixes white OAD lettering with dark partner logos, so no single background suits all of it. Decide how the partner band is built before using it.
- Sizes: the 1024px PNGs are 60 to 140 KB. Shown at header size, a smaller copy would load faster. Only make one if asked, and keep these originals.
- Add the source of any new logo file to `credits.md`.
